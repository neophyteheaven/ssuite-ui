Theme

The suite color-theme set — the same Quick Presets exposed in backoffice → SaaS → Settings. Pick one to fill all ten --color-brand-* bands and retheme every component on this page live. Default is SWEB · Blue.

Brand palette

The canonical --color-brand-50…900 token scale. Each utility (bg-brand-600, text-brand-500) resolves to a CSS variable, so an app retheme just overrides the variables. Try the theme swatches in the header.

Select Gateway

Settings-row pattern from SCRM → System Settings → Billing & Payments: a TomSelect gateway picker (leading icon + checkmark on the active option) that reveals the chosen gateway's credential fields. Pick a gateway to see it swap.

Payment Gateway

The gateway that collects subscription and invoice payments. Only the selected gateway's keys are used.

Tip: hit Test to verify your keys before saving, and keep Sandbox on until you go live.

Selecting a gateway will make it the default payment handler for all transactions.

Table toolbar

<x-table-toolbar> — search box on the left, filter + action slots on the right.

Data table

The admin grid (Yajra / DataTables). The Show entries dropdown and Search box are brand-styled to match form inputs; the active page pill uses --color-brand-600. App shells load jquery.dataTables.min.css/js + this control CSS.
